# FKUS — Apúntalo. Organízalo. Hazlo. ⚡

FKUS es una aplicación móvil de organización personal rápida, minimalista y directa. Su objetivo es ayudar al usuario a recordar, organizar y ejecutar todo aquello que tiene que hacer, tanto a corto como a largo plazo, sin perder tiempo gestionando su productividad.

## 🚀 Principales Características

- **Modo "Hoy":** Vista cronológica con actividades por hora, rutinas del día y tareas pendientes.
- **Captura Ultrarrápida (`+`):** Añade tareas en 2 segundos con auto-focus y campos expandibles opcionales.
- **Bandeja de Entrada (Inbox):** Vacía tus ideas sin la obligación de asignarles fecha inmediata.
- **Gestor de Tareas Atrasadas:** Reprogramación en un solo toque (*Hoy · Mañana · Esta semana · Elegir fecha*).
- **Calendario Visual:** Vistas de Semana (predeterminada), Día (horarios 07:00-22:00) y Mes con indicadores de categoría.
- **Rutinas:** Secuencias de hábitos organizadas por pasos (ej. *Rutina de mañana*, *Gimnasio*).
- **Objetivos a Largo Plazo:** Conexión directa a tareas reales (*"12 completadas · 8 pendientes"*, sin porcentajes artificiales engañosos) y cuenta atrás de días restantes.
- **Búsqueda Global:** Encuentra tareas, notas, objetivos y categorías al instante.
- **Categorías Personalizadas:** Iconos y paleta de colores a medida.
- **Privacidad y Respaldos:** Exportación e importación de copias de seguridad en formato JSON.

## 🛠️ Tecnologías

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **date-fns**
- **Canvas-Confetti**

## 💻 Instalación y Desarrollo Local

```bash
# Clonar el repositorio
git clone https://github.com/maarcsg27/fkus-app.git

# Entrar al directorio
cd fkus-app

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
